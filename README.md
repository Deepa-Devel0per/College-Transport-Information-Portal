# College Transport Information Portal

A simple and user-friendly web application designed to help students easily view college bus routes, pickup points, and transport timings in one place.

## 📌 Project Overview

The **College Transport Information Portal** provides a centralized place for students to check available bus routes and pickup details. The application includes search, filtering, route selection, and responsive design features for easy access on different devices.

## 🎯 Objectives

* Provide bus route information in one place.
* Display pickup points and timings clearly.
* Help students quickly find their required route.
* Provide a simple and user-friendly interface.
* Make the website responsive for desktop, tablet, and mobile devices.

## ✨ Features

* **Home / Dashboard** – Displays basic transport information and quick access to different sections.
* **Bus Routes** – Shows available bus routes and route details.
* **Pickup Points** – Displays pickup locations and timings.
* **Search / Filter** – Helps users find buses, routes, and pickup points quickly.
* **JavaScript Interaction** – Provides dynamic searching, filtering, route selection, and content display.
* **Responsive Design** – Works across desktops, tablets, and mobile devices.

## 🚀 How to Run

1. Download or clone the project.
2. Keep the folder structure unchanged.
3. Open the project folder.
4. Double-click **`index.html`**.
5. The portal will open in your web browser.
6. Use the navigation menu to explore routes, pickup points, and search features.
